# 보건의료 데이터 자료집

공공·임상·연구데이터 통합 자료 — 보건의료 연구자가 활용 가능한 국내 데이터를
제공기관별로 탐색할 수 있도록 데이터의 성격, 범위, 이용 절차와 활용 가능성을
통합 정리한 자료집입니다.

> **기준일** 2026년 8월 20일 (최종초안)
> **수록 규모** 총 39개 데이터 항목 · 본문 36개 + 부록 4개

---

## 이 자료집을 읽는 방법

1. 아래 **목차**에서 연구 주제에 맞는 제공기관·데이터를 찾습니다.
2. 각 데이터 항목의 `데이터 범위 및 최신성` → `데이터 획득` → `데이터 결합`
   순으로 검토합니다.
3. 단독 신청이 제한되는 데이터는 [7장 부록](docs/07-appendix.md)의
   결합·연계 이용조건을 추가로 확인합니다.

### 데이터 접근 유형

| 유형 | 설명 |
| --- | --- |
| 즉시 다운로드 | 공개 원시자료·통계자료를 신청·승인 후 내려받아 분석 |
| 심의 필요 | 기관 심의 후 지정된 분석환경에서 분석, 승인된 결과만 반출 |
| 연계·결합 | 특정 플랫폼을 통해 연계·결합 절차를 거쳐 제한적으로 이용 |

> 데이터 공개연도, 규모, 신청 절차, 비용 및 심의 요건은 제공기관 정책에 따라
> 변경될 수 있습니다. 실제 이용 전에는 반드시 제공기관의 최신 공고와 지침을
> 확인하시기 바랍니다.
